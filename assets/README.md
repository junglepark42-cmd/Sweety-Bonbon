# Ressources originales Sweety Bonbons

Les six bonbons, l’arc-en-ciel, le décor de forêt et les icônes PWA sont des dessins originaux du projet. Chaque bonbon possède sa propre silhouette et sa couleur ; le décor et les ressources de jeu sont des fichiers distincts.

Les mascottes `unicorn.webp` et `dino.webp` ont été créées avec l’outil intégré ImageGen pour ce jeu, puis converties en WebP avec conservation de la transparence. Elles ne proviennent pas d’affiches découpées. Les personnages de `junglepark42-cmd/Sweety-splash/assets` ont été consultés en lecture pour identifier la licorne violette et le dinosaure vert. Aucun fichier de cet autre dépôt n’a été modifié ou intégré.

Prompts ImageGen (génération, fond transparent) :

- Unicorn: “Use case: stylized-concept. Asset type: production game mascot PNG, transparent background. Create ONE full-body adorable purple unicorn, orange flowing mane and tail, golden spiral horn, friendly big eyes, little golden hoofs, holding one pink candy heart. Original Sweety Sweety children's candy forest game mascot. Polished soft 3D cartoon toy rendering, beautiful readable silhouette, warm joyful expression, no clothes, no text, no logo. Entire horn, tail and all four limbs fully inside image with generous transparent margins. Isolated character only, true alpha transparency, no floor or background.”
- Dino: “Use case: stylized-concept. Asset type: production game mascot PNG with true alpha transparency. ONE full-body adorable friendly green dinosaur with yellow-green belly, small rounded golden dorsal spikes, big expressive eyes, short snout, waving and holding a little spiral candy lollipop. Original Sweety Sweety candy forest game character. Soft polished 3D cartoon toy rendering, cheerful, cute child-friendly round proportions, no clothes, all limbs and complete tail inside image, generous transparent margins. No background, no floor, no text, no logos.”

Les sons sont synthétisés dans `js/audio.js` avec des oscillateurs sinusoïdaux. Aucun enregistrement ou service audio externe n’est employé. La typographie utilise les polices système de l’appareil ; aucun téléchargement de police n’est requis.
